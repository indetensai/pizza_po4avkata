# PIZZA_PO4AVKATA🍕
**PIZZA_PO4AVKATA** - это бэкенд-проект на языке Golang, который я создал с целью изучения того, как использовать gRPC и проектировать микросервисы. Проект имитирует службу доставки пиццы, где пользователи могут просматривать меню, делать заказы и отслеживать их доставку. Он использует Fiber, быстрый и легкий веб-фреймворк, для обработки HTTP-запросов и ответов. Проект использует MongoDB Atlas в качестве решения для базы данных, которое предлагает масштабируемый и безопасный облачный сервис для MongoDB. Он использует сессии для безопасной аутентификации и авторизации, чтобы защитить конечные точки и проверить пользователей. Он использует gRPC, высокопроизводительный фреймворк RPC, для обмена данными между микросервисами. Он использует Docker и docker-compose для простой развертки и переносимости. Проект построен с учетом принципов чистой архитектуры. Проект позволяет пользователям заказывать пиццу онлайн. Он состоит из трех микросервисов: сервиса пользователей, сервиса меню и сервиса заказов. Он также имеет API-шлюз, который принимает запросы и направляет их к подходящему сервису. **PIZZA_PO4AVKATA** - это веселый и образовательный проект, который демонстрирует преимущества gRPC и микросервисов в создании современных и надежных бэкенд-приложений. Это также отличный способ продемонстрировать свои навыки в Golang и впечатлить потенциальных работодателей и клиентов своей страстью к пицце.

## Как запустить
Прежде чем продолжить, убедитесь, что вы выполнили следующие требования:
- У вас установлена последняя версия Go.
- Вы установили MongoDB и создали базу данных для проекта (альтернативный вариант - использовать MongoDB Atlas).
- Вы создали файлы .env с необходимыми переменными окружения.
- Вы установили gRPC.

Чтобы запустить **PIZZA_PO4AVKATA**, выполните следующие шаги:
1. Клонируйте этот репозиторий: `git clone https://github.com/indetensai/pizza_po4avkata.git`
2. Перейдите в директорию проекта: `cd pizza_po4avkata`
3. Установите зависимости: `go mod download`
4. Заполните файлы .env необходимыми переменными окружения.
5. Соберите исполняемый файл: `go build -o pizza_po4avkata cmd/pizza_po4avkata/main.go`
## Как запустить (docker-compose)
Прежде чем продолжить, убедитесь, что вы выполнили следующие требования:
- У вас установлена последняя версия docker(-desktop).

Чтобы запустить **PIZZA_PO4AVKATA** с помощью docker-compose, выполните следующие шаги:
1. Клонируйте этот репозиторий: `git clone https://github.com/indetensai/pizza_po4avkata.git`
2. Перейдите в директорию проекта: `cd pizza_po4avkata`
3. Запустите `docker compose up`

## Использование
Чтобы запустить **PIZZA_PO4AVKATA**, выполните следующие шаги:
1. Запустите исполняемый файл: `./pizza_po4avkata`
2. Чтобы взаимодействовать с API, вы можете использовать любой HTTP-клиент на ваш выбор.

API **PIZZA_PO4AVKATA** имеет следующие конечные точки:
- `POST /user/register`: Создать новую учетную запись пользователя.
- `POST /user/login`: Войти с существующей учетной записью пользователя и получить сессию.
- `GET /menu`: Получить меню.
- `POST /order`: Сделать заказ с указанными блюдами. Требуется аутентификация.
- `GET /admin/orders`: Получить список заказов и их статус. Требуются права администратора.
- `POST /admin/pizza`: Создать блюдо в меню. Требуются права администратора.
